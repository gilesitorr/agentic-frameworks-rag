# Source document

The demo summarizes the **ResNet** paper ("Deep Residual Learning for Image Recognition"),
included here as `resnet.pdf` so the demo runs with no extra steps.

- Source: https://arxiv.org/pdf/1512.03385
- Copyright of its authors; included for demo purposes only.

It is the **same document** for every implementation, so differences in the output come
from how each one is orchestrated, not from the input.
