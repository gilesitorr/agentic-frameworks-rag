# Documento fuente

La demo resume el paper de **ResNet** ("Deep Residual Learning for Image Recognition", He et al., 2015).

Descarga el PDF desde arXiv y guárdalo aquí como `resnet.pdf`:

- https://arxiv.org/abs/1512.03385 → botón **Download PDF**
- o directo: https://arxiv.org/pdf/1512.03385

```
data/resnet.pdf
```

El PDF no se versiona en git (ver `.gitignore`); cada quien lo descarga. Así las tres
implementaciones resumen exactamente el mismo documento.
